# Royal Wellness Orbit

Create a premium, modern hero section for the Royal Medical Center homepage.

This is a fresh Lovable chat, so do not assume any previous design decisions or implementation.

Brand

Royal Medical Center

The website is a modern healthcare and wellness clinic focused on personalized:

Hormone Therapy

Testosterone Replacement Therapy

Women's Hormone Therapy

Weight Management

Peptide Therapy

Sexual Wellness

The hero should communicate personalized healthcare, wellness, energy, confidence, and balance.

Do NOT make it look like a traditional hospital website.

HERO DESIGN

Create a visually impressive, premium hero section with this headline:

Feel Better.

Live Better.

Be Your Best.

Eyebrow:

PERSONALIZED HORMONE & WELLNESS CARE

Description:

Personalized programs designed around your health, your goals, and your journey.

Primary CTA:

Get Started →

Secondary CTA:

Explore Programs

Pricing/trust text:

Personalized Programs
Starting at $67/mo*

VISUAL DIRECTION

Use a modern two-column composition.

LEFT — CONTENT

The left side should contain:

Small uppercase eyebrow

Large headline

Supporting paragraph

Two CTA buttons

Small pricing/trust element

Use large, elegant typography with generous spacing.

The headline should be the main visual focus.

Highlight “Be Your Best.” using the brand accent color.

RIGHT — WELLNESS VISUAL

Create a large premium wellness-focused visual.

Use a high-quality image of a healthy, confident adult/person with a natural lifestyle/healthcare aesthetic.

The person should look:

Healthy

Confident

Energetic

Natural

Professional

Approachable

Avoid generic hospital imagery.

DO NOT use:

Hospital beds

Doctors with stethoscopes

Medical equipment

Operating rooms

Generic hospital stock photography

The visual should feel closer to a premium wellness brand than a conventional medical website.

ANIMATED WELLNESS ORBIT

This is the most important visual element.

Build a sophisticated SVG wellness orbit system around the main person/image.

Place six floating wellness cards around the visual:

More Energy
Radiant Skin
Restful Sleep
Sexual Wellness
Balanced Mind
Thicker Hair

Create an elegant circular/organic SVG path connecting these elements.

The person should remain the focal point.

The wellness cards should feel like floating information nodes around the person.

ANIMATION

Use subtle, premium animation.

Main visual

Very subtle breathing/scale animation

Gentle floating movement

Orbit

Slowly rotate the orbit

Keep rotation very slow and smooth

Add subtle glowing particles moving along the SVG path

Wellness cards

Each card should gently float with slightly different animation timing.

Do not make them bounce aggressively.

Mouse interaction

On desktop, add subtle mouse-based parallax:

Main visual moves slightly

Orbit shifts slightly

Decorative elements react subtly

Keep the effect minimal and smooth.

CTA

On hover:

Arrow moves slightly to the right

Button has a subtle elevation/glow effect

Important

The animation must feel:

Premium
Calm
Modern
Futuristic
Healthcare-focused

NOT flashy.

Support prefers-reduced-motion.

BACKGROUND

Use a predominantly light background.

Create subtle depth using:

Soft radial gradients

Very light brand-colored gradients

Organic SVG blobs

Fine decorative lines

Tiny floating particles

Keep plenty of whitespace.

Do NOT use a busy background.

Do NOT use a dark blue hospital-style hero.

FLOATING PRICING CARD

Add a small floating card near the hero visual.

Content:

PERSONALIZED PROGRAMS

Starting at

$67/mo*

Design it with subtle:

Glassmorphism

Backdrop blur

Thin border

Soft shadow

Rounded corners

The card should remain secondary to the main visual.

VISUAL HIERARCHY

The user's eye should naturally follow:

Headline

Person / main visual

CTA

Wellness orbit

Pricing card

Do not let the floating elements compete with the headline.

RESPONSIVE DESIGN

Desktop

Use approximately:

45% content / 55% visual

Hero should occupy approximately 85–95vh.

Keep the content vertically centered.

Tablet

Reduce:

Heading size

Orbit size

Spacing

Keep the composition balanced.

Mobile

Stack vertically:

Eyebrow

Headline

Description

CTA buttons

Pricing element

Main visual

Wellness cards

Simplify the orbit on mobile so it does not become cluttered.

Make sure nothing overlaps or goes outside the viewport.

DESIGN STYLE

The overall visual language should combine:

Premium wellness brand
+
Modern healthcare
+
Personalized treatment
+
Subtle futuristic technology

The result should feel like a high-end healthcare/wellness landing page designed in 2026.

Avoid looking like a generic WordPress healthcare template.

TECHNICAL REQUIREMENTS

Build this as a production-ready responsive hero section.

Use:

Semantic HTML

Clean component structure

Responsive CSS

SVG for decorative/animated elements

CSS transforms and opacity for animations

Accessible buttons

Proper heading hierarchy

Good color contrast

prefers-reduced-motion

Avoid unnecessary dependencies.

Do not use heavy video backgrounds.

Keep animations performant.

APPROVED CONTENT

Use exactly these hero messages:

Eyebrow:
PERSONALIZED HORMONE & WELLNESS CARE

Headline:
Feel Better. Live Better. Be Your Best.

Description:
Personalized programs designed around your health, your goals, and your journey.

Wellness benefits:
More Energy
Radiant Skin
Restful Sleep
Sexual Wellness
Balanced Mind
Thicker Hair

Pricing:
Starting at $67/mo*

Buttons:
Get Started
Explore Programs

Do not invent testimonials, statistics, medical claims, awards, certifications, patient results, or guarantees.

FINAL GOAL

The hero should immediately communicate:

“Royal Medical Center provides modern, personalized healthcare designed to help me feel healthier, more energetic, confident, and balanced.”

Make the final result visually impressive, premium, clean, responsive, and animation-rich without becoming distracting.
